# Forgeline

Безкоштовна браузерна гра про фабрику й оборону бази, натхненна Mindustry. Увесь код і графіка оригінальні, один файл `index.html`, без залежностей та інтернету.

## Грати
Відкрийте `index.html` у браузері або на GitHub Pages (Settings → Pages → Branch `main` → Save).

## Що є
- Політ власним літаком: стріляє по ворогах, добуває руду, будує.
- 6 секторів, нові блоки відкриваються з проходженням.
- Конвеєри (у т. ч. титановий), перехрестя, маршрутизатор, бури, прес, піч, енергія.
- Турелі: Дуо, Град, Скаттер, Лансер; стіни та ремонтник.
- Вороги: кинджал, флар, мейс, горизонт.
- Автозбереження, пауза, звук (кнопки справа).

## Керування
- Телефон: лівий джойстик, дотик будує, ⛏ видобуває, щипок міняє масштаб.
- Комп'ютер: WASD політ, миша будує, колесо масштаб, R поворот, Q скинути інструмент.
